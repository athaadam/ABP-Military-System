================================================================================
                              IF YOU GET ERROR
================================================================================

ERROR: "Connection refused"
  → Make sure backend API is running at http://localhost:5000

ERROR: "Invalid credentials"
  → Check your backend for correct email/password

ERROR: "Flutter not found"
  → Install Flutter SDK: https://flutter.dev/docs/get-started/install

ERROR: "Chrome crashed"
  → Use Windows instead: flutter run -d windows
